# 造世界游戏试玩

- `exam.html`：逢考必过，俯视2D怀旧娱乐考场。
- `memory.html`：春日存档，2019至2020合作密室解谜演示。

使用 GitHub Pages 发布仓库主分支根目录。所有运行文件随站点提供，不需要启动服务器或安装依赖。考试首次开局会加载 Python WebAssembly 运行组件，规则来源为 `exam.py`；不会发送玩家答卷到外部服务。运行组件为 Pyodide 0.27.7（Mozilla Public License 2.0，https://github.com/pyodide/pyodide）。

考试真人模式限同一浏览器的多个标签页，不支持跨设备联机；密室演示为单人操作，可同屏讨论。考试考场保存在浏览器网站数据中，密室刷新重开。两个游戏均为玩法验证版本。

`assets/memes/077.gif` 与 `038.jpg` 来源于 ChineseBQB 精选（https://github.com/zhaoolee/ChineseBQB），用于相关怀旧题目的演示；商业活动使用素材需另行核对。其他插画及界面用于本项目演示。
